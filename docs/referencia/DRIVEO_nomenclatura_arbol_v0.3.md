# DRIVEO — Nomenclatura jerárquica

La nomenclatura de los diagramas sigue el árbol Área → Módulo → Función. Es un identificador del análisis, no un código oficial ni una ruta técnica del ERP.

- Org.1: Organización.
- Org.1.1: Organización / Empresas y Usuarios.
- Org.1.1.1: Organización / Empresas y Usuarios / Tablero.

El número central del área sigue el orden del menú observado. Los siguientes niveles siguen el orden de los módulos y funciones en ese menú. Las secciones agrupan procesos, pero no renumeran los módulos.
